# Bug Fixes — Separate Panels, Single Overlay, No Edit Button

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) to implement this plan.

**Goal:** Fix three UX bugs: (1) Effects as separate panel next to Region with 4-column layout, (2) Only show active effect's overlay (not all enabled), (3) Remove "Edit region" button — card click always activates region.

**Architecture:** region.js gains `showAllOverlays` flag. app.js removes regionRow from cards. HTML splits into 4-column grid with separate Region and Effects panels. CSS updates grid + new panel styles.

## Global Constraints

- Zero npm dependencies
- 4-column workspace: Input | Region (220px) | Effects (300px) | Output
- region.js `renderAll()`: show only active overlay when `showAllOverlays = false`
- "Show all regions" toggle in Region panel switches to read-only visualization mode
- No "Edit region" button — clicking card header = activate region

- [ ] **Step 1: Add showAllOverlays flag to region.js**

In `js/ui/region.js`, add a `showAllOverlays` flag (default false) and update `renderAll()` to only show the active overlay when it's false:

```js
// After the dragging state variables (around line 35), add:
let showAllOverlays = false;

// In renderAll(), replace the loop (lines 112-127) with:
function renderAll() {
  for (const [id, els] of Object.entries(overlays)) {
    if (!enabledEffects[id]) {
      els.handle.style.display = 'none';
      continue;
    }
    // When not showing all, only render the active effect's overlay
    if (!showAllOverlays && id !== activeId) {
      els.handle.style.display = 'none';
      continue;
    }
    const r = regions[id];
    if (!r) continue;
    const d = toDisplay(r);
    els.handle.style.display = '';
    els.handle.style.left = `${d.x}px`;
    els.handle.style.top = `${d.y}px`;
    els.handle.style.width = `${d.w}px`;
    els.handle.style.height = `${d.h}px`;
    // All solid when showing all (read-only viz), or solid for active when editing
    els.handle.style.borderStyle = showAllOverlays ? 'dashed' : 'solid';
    els.handle.style.pointerEvents = showAllOverlays ? 'none' : 'auto';
  }

  // Sync inputs to active effect (only when editing, not in showAll mode)
  if (!showAllOverlays && activeId && regions[activeId]) {
    const ar = regions[activeId];
    inputs.left.value = ar.x;
    inputs.top.value = ar.y;
    inputs.width.value = ar.w;
    inputs.height.value = ar.h;
  }
}
```

Add `toggleShowAll()` to the return object:
```js
// In the return object, add:
toggleShowAll() {
  showAllOverlays = !showAllOverlays;
  renderAll();
  return showAllOverlays;
},
```

- [ ] **Step 2: Fix app.js — remove "Edit region" button, card click always activates**

Remove the regionRow with "Edit region" button (lines ~109-124). Replace with nothing — the card body just has the slider.

Update `toggleEffect()` to always activate region on click (not just on first enable):
```js
// Replace the toggleEffect function (lines ~127-140):
const toggleEffect = () => {
  const wasEnabled = effectEnabled[effect.id];
  effectEnabled[effect.id] = !wasEnabled;
  toggle.textContent = effectEnabled[effect.id] ? '●' : '○';
  body.style.display = effectEnabled[effect.id] ? '' : 'none';
  card.classList.toggle('effect-card--enabled', effectEnabled[effect.id]);

  if (effectEnabled[effect.id]) {
    // Always activate region when enabling an effect
    regions.setActiveEffect(effect.id);
    updateRegionInputsVisibility(effect.id);
  }

  updateAllOverlays();
};
```

Also update the card header click behavior: clicking on an already-enabled card should also activate its region (for the case where user wants to switch which effect's region they're editing):
```js
// After the existing toggle click handler:
header.addEventListener('click', (e) => {
  // Don't toggle if clicking slider or other interactive elements
  if (e.target.tagName === 'INPUT' || e.target.tagName === 'BUTTON') return;
  const wasEnabled = effectEnabled[effect.id];
  if (!wasEnabled) {
    // Enable it
    toggleEffect();
  } else {
    // Already enabled — just activate its region
    regions.setActiveEffect(effect.id);
    updateRegionInputsVisibility(effect.id);
    updateAllOverlays();
  }
});
```
