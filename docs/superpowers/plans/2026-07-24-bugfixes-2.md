- [ ] **Step 2: Bug 3 — Fix resize handle by calling setActiveEffect in both branches**

In `js/ui/region.js`, change the mousedown handler (lines 58-68) to call `setActiveEffect(effectId)` before `dragRegion`:

```js
handle.addEventListener('mousedown', (e) => {
  setActiveEffect(effectId);  // ALWAYS set active, for both drag and resize
  if (e.target === resize) {
    resizing = true;
  } else {
    dragging = true;
  }
  dragStart = { x: e.clientX, y: e.clientY };
  dragRegion = { ...(regions[activeId] || regions[effectId] || { x: 0, y: 0, w: 200, h: 200 }) };
  e.preventDefault();
  e.stopPropagation();
});
```
